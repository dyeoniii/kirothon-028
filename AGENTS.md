# Team agent rules — Catch Trolls
- Read `docs/requirements-mvp.md`, `docs/api-contract.md`, `docs/internal-interfaces.md`, and `docs/session-ownership.md` before edits.
- **Four independent sessions; no overlapping edits.** S1 only `frontend/**`; S2 `backend/app/documents/**`, `samples/**`, `docs/presentation/**`; S3 backend API/model/schema/db/main/dependencies; S4 `backend/app/analysis/**` and `backend/app/collectors/**`.
- Shared configuration and docs are frozen during parallel development. Propose changes to the human integrator.
- Do not invent the content of screenshots, usernames, timestamps, URLs or legal conclusions.
- An AI classifier provides review signals, not legal advice or a conclusion of criminal liability.
- Do not commit secrets or expose APIs to clients. Local single-user demonstration only.
- Report files changed, tests actually run, known failures, and needed integrations; never claim unrun tests passed.
