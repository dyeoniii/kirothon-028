# Requirements — Catch Trolls MVP (P0)

원본: `docs/requirements-mvp.md`, `docs/api-contract.md`. 충돌 시 docs가 우선한다.

## Introduction
SNS 악성 댓글을 판독하고 증거를 보관해 법적 대응을 준비하도록 돕는 모바일 우선 웹앱. AI 분석은 법률 자문이 아니며 고소 성립이나 승소를 판단하지 않는다.

## Requirements

### R-01 사건 관리
**User Story:** 사용자로서 사건을 만들고 목록·상세를 보고 싶다. 그래야 증거를 사건 단위로 모을 수 있다.

1. WHEN 사용자가 제목과 설명을 제출하면 THEN 시스템은 사건을 생성하고 `created_at`(UTC)을 기록한다.
2. WHEN 사건을 삭제하면 THEN 시스템은 연관 소스·댓글·판독·서버에 저장된 원본 이미지를 함께 삭제하고 204를 반환한다.

### R-02 텍스트 입력
1. WHEN 사용자가 텍스트를 붙여넣으면 THEN 시스템은 줄 단위로 댓글을 분리해 확인·수정 가능한 목록으로 보여준다.
2. 사용자는 원본 게시글 맥락(`context`)과 출처 URL을 추가로 입력할 수 있다.

### R-03 이미지 입력
1. WHEN `.png/.jpg/.jpeg/.webp` 파일(최대 10MB)을 업로드하면 THEN 시스템은 Gemini 비전으로 댓글을 추출한다.
2. IF 작성자나 시각을 읽을 수 없으면 THEN 해당 필드는 `null`이며 추측하지 않는다.
3. 시스템은 원본 파일의 SHA-256과 수집 시각(UTC)을 저장한다.
4. IF 형식이나 크기가 제한을 넘으면 THEN `VALIDATION_ERROR`를 반환한다.

### R-04 URL 입력
1. WHEN YouTube `watch`, `youtu.be`, `shorts` URL이 입력되면 THEN 시스템은 영상 ID를 파싱해 공개 댓글과 답글을 합산 최대 200개 가져온다.
2. IF API 한도 초과, 비공개, 댓글 비활성화로 실패하면 THEN 오류와 수동 입력 안내를 보여준다.
3. IF 다른 플랫폼 URL이면 THEN 스크래핑 없이 출처만 저장하고 `type=url_only`, `needs_manual_input=true`를 반환한다.

### R-05 SNS 공유 수신
1. 설치형 PWA는 manifest `share_target`으로 `/share-target?url=...`을 받고 URL 입력 탭만 프리필한다.
2. 자동 수집·분석은 사용자의 명시적 클릭 이후에만 시작한다.
3. IF 환경이 미지원이면 THEN 링크 복사 후 붙여넣기 경로를 제공한다.

### R-06 AI 판독
1. WHEN 선택한 댓글(최대 20건)을 분석하면 THEN 시스템은 `legal_review`, `needs_context`, `low_risk` 중 하나와 문제 문구 인용, 이유, 검토 쟁점, 추가 확인 질문을 반환한다.
2. 시스템은 모델 응답을 Pydantic으로 검증하고 실패 시 한 번만 재시도한다.
3. 댓글, 원글, OCR 내용은 분석 데이터이며 모델에 대한 지시로 취급하지 않는다.
4. 모든 결과에 "AI 분석은 법률 자문이 아닙니다" 고지를 포함한다.

### R-07 증거 보관
1. 사용자는 댓글을 `saved` 상태로 표시하고 메모와 확인 여부를 남길 수 있다.
2. 시스템은 원문 댓글과 원본 이미지를 수정하지 않는다.

### R-08 누락 정보 확인
1. 시스템은 저장된 증거 기준으로 체크리스트와 질문을 만들고 사용자 답변을 저장한다.
2. 완성도(%)는 서비스 내 항목 작성률이며 법적 충분성을 뜻하지 않는다.

### R-09 PDF 2종
1. 시스템은 사건 경위서와 증거 목록 PDF를 한국어로 생성한다.
2. PDF는 "확인된 사실"과 "AI 분석 추정"을 분리하고 법률 자문 아님 고지를 넣는다.
3. 저장된 데이터에 없는 사실, 작성자, 시각은 만들지 않는다.
4. IF 증거가 없으면 THEN 이해 가능한 오류를 반환한다.

### R-10 안전
1. API 키는 서버 `.env`에만 두고 프론트와 저장소에 노출하지 않는다.
2. 외부 AI에는 필요한 최소 정보만 전달한다.
3. 실패 응답은 `{"error":{"code","message"}}` 형식을 따른다.
