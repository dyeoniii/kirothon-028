# 제품 정의
- 이름: **Catch Trolls** — SNS 악성 댓글 판독·증거 관리·법적 대응 준비 웹앱
- 대상: 일반 사용자(모바일 우선). 크리에이터 지원은 확장 대상.
- 핵심: `텍스트/이미지/URL/SNS 공유 링크 → 댓글 선택 → AI 위험 신호 판독 → 사건 증거 보관 → 누락정보 확인 → PDF 2종`
- SNS 공유 URL 수신 및 직접 URL 입력 **모두 1차 MVP**. YouTube 공식 API 조회만 자동 수집, 그 외 플랫폼은 URL 출처 보관 + 수동 입력.
- 1일/2명/4세션/3,000크레딧(계정 A 1,000 + 계정 B 2,000) 제약.
- 분석 단계: `legal_review` / `needs_context` / `low_risk`, 법률 자문 아님.
- 고소 가능 확정·승소률 예측 금지, 출처·작성 시각 없는 사실 창작 금지. 사용자 사실과 AI 추정 구분.
- 자세한 완료조건: `docs/requirements-mvp.md`.
